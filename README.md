### Что умею

- React 19 + TypeScript в строгом режиме. Типизирую всё от запроса к API до пропсов компонента - лучше поймать ошибку на этапе написания, чем потом ловить в проде.
- Верстаю по макетам из Figma на Tailwind.
- Zustand для состояния, React Router и Axios 
- Бэкенда не боюсь: Express, Prisma, PostgreSQL. Понимаю, как устроена серверная часть, поэтому с бэкендерами договориться легко.
- В Школе 21 пишу на чистом C - алгоритмы, память, указатели. Хорошо вправляет мозги.
